# Brain: start here

This folder is the team's shared memory for AegisMargin. Read it in this order and you will know what is going on in about 10 minutes.

| File | What it answers |
|---|---|
| [CONTEXT.md](CONTEXT.md) | What are we building and why? Who does what? |
| [STATUS.md](STATUS.md) | Where are we right now? What is done, what is in progress? |
| [NEXT_STEPS.md](NEXT_STEPS.md) | What should be done next, in order? |
| [DECISIONS.md](DECISIONS.md) | What did we choose, and why? |
| [LOG.md](LOG.md) | What worked, what failed, what we learned (newest first) |
| [SETUP.md](SETUP.md) | How do I get the code running on my machine? |

Rules for keeping it useful:
- Update `STATUS.md` and `LOG.md` at the end of every work session.
- Write in plain words. If a colleague can't follow it, rewrite it.
- Never put secrets, keys or passwords in here.
- Original source docs (do not edit): `NEAR_HACKATHON_PROJECT_CONTEXT.md` and `docs/IMPLEMENTATION_PLAN.md` on `main`.
